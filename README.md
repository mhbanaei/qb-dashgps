# QBCore GPS Waypoint Script
This script allows players to set a waypoint on the map by using the /gps command. Locations are predefined in config.lua, where each location has a unique vector3 coordinate and a custom color. If a player enters /gps without any code, the currently set waypoint will be removed.

🔹 Features:
✅ Set Waypoints: Players can use /gps  to mark a location on the map.
✅ Remove Waypoints: Entering /gps without any arguments clears the waypoint.
✅ Customizable Locations: All locations are stored in config.lua with vector3 coordinates.
✅ Custom Colors: Each waypoint can have its own color defined in HEX format, which is converted to RGB for compatibility.
✅ QBCore Notifications: Displays success/error messages when setting or clearing waypoints.

This script is perfect for roleplay servers where players need a quick and easy way to navigate predefined locations!
